  ツルの一声  v1.2.0
  画面のツルをクリックすると、雑学をひとつ教えてくれるアプリ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 動作環境
  Windows 10 / 11 (64bit)
  インストール不要。.NET などの追加ソフトも不要です。

■ はじめかた
  1. この zip を好きな場所に展開します。
  2. TsuruNoHitokoe.exe をダブルクリックします。
  3. 画面の右下に折り鶴のアイコンが現れます。

  ※ 初回起動時に「Windows によって PC が保護されました」と表示された場合は、
     「詳細情報」→「実行」を押してください。
     (個人制作のアプリで、有料の電子署名を付けていないために表示されます)

■ 使いかた
  クリック ………… 雑学をひとつ話します(もう一度クリックで次の雑学)
  ドラッグ ………… ツルを好きな場所へ移動できます(位置は記憶されます)
  右クリック ……… メニューを開きます

  吹き出しは少しすると自動で消えます。吹き出しをクリックしてもすぐ消せます。
  ニュースのときは、吹き出しの「続きを読む ›」で記事をブラウザで開けます。
  タスクトレイ(画面右下の ^ の中)のツルのアイコンからも操作できます。

■ メニュー
  一声もらう …………… 雑学をひとつ表示
  話す内容 ……………… 雑学 / 今日の出来事 (Wikipedia) / 最新ニュース / まぜる
                          「今日の出来事」はその日の日付の過去の出来事、
                          「最新ニュース」は直近24時間のニュースの見出しを
                          インターネットから取ってきます。
                          つながらないときは雑学を話します。
  ニュースの取得元 …… Google ニュース / NHK ニュース / 両方
  自動でつぶやく ……… 5分 / 10分 / 15分 / 30分 / 1時間 / 3時間ごとに自動で話します
  表示時間 ……………… 吹き出しを出しておく時間を、雑学・今日の出来事・ニュース・時報
                          ごとに選べます(文の長さに合わせる / 5秒〜1分 / 閉じるまで)。
                          「読む速さ」(ゆっくり / ふつう / はやい)で、
                          「文の長さに合わせる」ときの長さを調整できます。
  毎時の時報 ………… 毎時0分に「午後3時になりました。」のようにお知らせします
  ツルの大きさ ………… 小 / 中 / 大
  ツルを隠す …………… アイコンを隠します(トレイアイコンから呼び戻せます)
  一声帳を開く ………… ツルが話す雑学の一覧を開きます。
                          書き足す・書き換える・消すことができ、「保存」で反映されます。
                          「デフォルトに戻す」で最初から入っている雑学に戻せます。
  Windows 起動時に呼ぶ … パソコンを起動したときに自動でツルが現れます
  アップデート ………… 「新しいバージョンを確認する」で今すぐ確認できます。
                          「新しいバージョンが出たら知らせる」がオンなら、
                          起動後と1日1回確認して、新しいものがあればツルが知らせます。
  終了

■ アップデートのしかた
  1. ツルのお知らせの「ダウンロードページへ ›」から、新しい zip をダウンロード
  2. ツルを右クリック →「終了」
  3. 今の TsuruNoHitokoe.exe を、新しい exe で同じ場所に上書き
  4. 新しい exe を起動
  設定や一声帳の内容はそのまま引き継がれます。
  ※ 別のフォルダに置いた場合は、「Windows 起動時に呼ぶ」を一度外して付け直してください。

■ アンインストール
  1. メニューの「Windows 起動時に呼ぶ」にチェックが付いていたら外す
  2. 「終了」でアプリを閉じる
  3. TsuruNoHitokoe.exe を削除
  4. 設定や編集した一声帳も消す場合は、次のフォルダを削除
       %APPDATA%\TsuruNoHitokoe
     (エクスプローラーのアドレス欄に貼り付けると開けます)
